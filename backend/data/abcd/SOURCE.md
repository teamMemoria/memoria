# ABCD records used by the knowledge pipeline

These files are third-party data. They are kept apart from the tests we wrote
(`tests/knowledge/`) and from anything the pipeline generates (`results/`,
`examples/`).

## What is here

| Path | What it is | Changed? |
|---|---|---|
| `conversations/ABCD-*.json` | The 100 ABCD conversations from the team's curated set, one file each | No. Byte-for-byte copies |
| `splits.json` | Which ABCD split (`train` / `dev` / `test`) each record came from | Generated by `scripts/build_abcd_splits.py` |
| `LICENSE-ABCD` | ABCD's licence | No. Copied from the ABCD repository |

## Where it comes from

- **ABCD (Action-Based Conversations Dataset)**, © 2021 ASAPP Research, MIT
  licence. https://github.com/asappresearch/abcd at commit
  `6b8700ce67c6b37b062dd7a60abc76d7ef832a97`. Cite: Chen, Chen, Yang, Lin, Yu.
  *Action-Based Conversations Dataset: A Corpus for Building More In-Depth
  Task-Oriented Dialogue Systems.* NAACL 2021. arXiv:2104.00783.
- **Curated selection**, from
  https://github.com/marcomarchesanogenesys/uoft-ftli-2026-genesys-docs at commit
  `c39d2e0610417256bf05811b774d400deea7456f`, `curated/conversations/`. The
  only change it makes to ABCD is the one it documents: ABCD's `products` string
  is parsed into JSON. `modifications` is `[]` on every record here.

The MIT licence requires the copyright and permission notice to travel with
the data. That is why `LICENSE-ABCD` is here. Don't remove it.

## Things to keep in mind

- The people, accounts, addresses and policies in ABCD are invented for the
  dataset. **ABCD guidance is not real company policy.**
- No real call data goes in this folder or anywhere else in the repo (see the
  top-level README).
- `splits.json` keeps ABCD's own split. Labelled evaluation cases follow it, so
  held-out cases never come from conversations used for tuning.
